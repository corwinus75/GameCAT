# GameCAT 1.1.1 — poprawka inicjalizacji asynchronicznego GUI

**Baza:** GameCAT 1.1.0. **Schemat SQLite:** bez zmian; otwieranie istniejących projektów nie wymaga migracji.

## Objawy i przyczyna

Zmiana minimalnego podobieństwa w panelu Translation Memory powodowała wyjątek:

```text
AttributeError: 'MainWindow' object has no attribute '_tm_generation'
```

`MainWindow._update_current_tm()` inkrementuje licznik generacji do odrzucania nieaktualnych wyników workerów. W 1.1.0 konstruktor `MainWindow.__init__()` nie ustawiał tego licznika. Tak samo brakowało innych pól używanych przez asynchroniczne QA, filtrowanie, nawigację i `closeEvent`.

## Poprawka

Pola inicjalizowane bezwarunkowo **przed połączeniem sygnałów GUI**:

| Pole | Wartość początkowa | Zastosowanie |
| --- | --- | --- |
| `_closing` | `False` | kontrola publikowania wyników i zamykania |
| `_tm_generation`, `_qa_generation`, `_quality_generation`, `_content_generation` | `0` | odrzucanie nieaktualnych wyników i rozpoznawanie zmian |
| `_tm_future`, `_qa_future`, `_quality_future` | `None` | anulowanie oczekujących zadań |
| `_pending_qa_jump` | `None` | nawigacja do wyniku asynchronicznego filtra QA |

Nie zmieniono zachowania wyszukiwania TM ani progu similarity; usunięto wyłącznie błąd inicjalizacji stanu i dodano testy regresyjne.

## Testy

- `tests/test_patch_111_async_init.py` — niezależny od Qt test regresyjny, który sprawdza inicjalizację i kolejność względem połączeń sygnałów.
- `tests/test_patch_111_async_qt.py` — test integracyjny rzeczywistego GUI w trybie `QT_QPA_PLATFORM=offscreen` (wymaga PySide6).
- Kompatybilność: istniejące testy async TM/QA i procesu zapisu.

## Weryfikacja ręczna na Windows

1. Otwórz projekt z segmentami i TM.
2. W panelu **TM** zmień „Minimalne podobieństwo” np. z 45% na 85% i z powrotem. Nie powinien pojawić się komunikat błędu.
3. Przechodź między segmentami; sugestie TM i panel QA powinny aktualizować się prawidłowo.
4. Użyj filtra „Błędy QA”, uruchom pełny skan QA, zamknij program przy aktywnym projekcie; nie powinien wystąpić `AttributeError` związany z brakującymi polami.
5. Otwórz bazę ponownie i sprawdź, czy próg TM został zapisany.

**Ograniczenie:** bez PySide6 nie da się wykonać realnego testu GUI. Test AST nie zastępuje testu okienkowego.
