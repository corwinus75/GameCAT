# GameCAT 1.2.5 — import plików CSV z różnymi separatorami

## Przyczyna błędu

Importer źródeł oraz okno wyboru kolumn zakładały separator przecinka. Pliki
lokalizacyjne `Id;Loca` (m.in. `com.ownedbygravity.fg2.invasion.EN.csv`)
były odczytywane jako jedna kolumna `Id;Loca`. Nie dało się prawidłowo
wskazać dwóch różnych pól Key/Source. Dodatkowo `Loca` nie było rozpoznawane
jako sugerowana nazwa pola źródłowego.

## Zmiany

- Automatyczna detekcja separatora **przecinek, średnik, tabulator, pionowa kreska**
  na podstawie **nagłówka CSV** (z uwzględnieniem cudzysłowów). Wybór nie zależy
  od liczby przecinków w długich opisach tekstowych.
- Okno importu poprawnie pokazuje kolumny `Id` i `Loca`, domyślnie sugeruje
  **Key / ID = Id**, **Source = Loca**, **Target = (brak)**. CSV bez kolumny
  ID może korzystać z pozycji wiersza jako identyfikatora.
- `ProjectService.import_file_async` rozpoznaje kolumny także przy imporcie
  bez jawnego mapowania (np. automatyczne testy, integracje CLI).
- Identyczny mechanizm dla importu plików zawierających tylko tłumaczenia
  (`import_translation_csv`) i źródeł profilowanych (`read_source`).
- Eksport do **oryginalnego szablonu CSV** zachowuje jego separator, a
  pozostałe kolumny pozostają bez zmian. Nowy eksport płaski bez szablonu
  nadal zapisuje poprawny CSV rozdzielany przecinkami.
- Weryfikacja liczby kolumn: błędny rekord kończy import komunikatem,
  zamiast cichego odrzucenia nadmiarowych pól.
- Zachowanie oryginalnych tekstów, w tym `\\n`, znaków `;` w cytowanych
  wartościach oraz tagów gry. Sekwencje `\\n` **nie są dekodowane** do fizycznych
  znaków nowej linii.
- **Brak migracji SQLite.** Istniejące mapowania i pliki CSV z przecinkami
  pozostają zgodne.

## Weryfikacja

Sprawdzono bezpośredni import załączonego pliku gry: **7/7 rekordów**, a
`Source` i `Key` są identyczne z oryginałem. Testy regresyjne sprawdzają
średniki, przecinki wewnątrz tekstu, BOM UTF-8, znaki specjalne, import
`Target`, eksport na szablonie i błędną liczbę kolumn.

## Instrukcja użytkownika

1. Otwórz projekt GameCAT i wybierz **Importuj plik źródłowy**.
2. Wskaż plik `com.ownedbygravity.fg2.invasion.EN.csv`.
3. W oknie mapowania sprawdź **Klucz / ID: Id**, **Tekst źródłowy: Loca**,
   **Tłumaczenie: (brak)**, po czym zatwierdź.
4. Projekt powinien zawierać 7 segmentów.

Przed importowaniem do istniejącego projektu upewnij się, że plik nie został
już wcześniej zaimportowany, by nie utworzyć duplikatów segmentów.

## Ograniczenia

Używane jest kodowanie UTF-8/UTF-8 z BOM. Pliki w CP1250 wymagają konwersji.
Testy GUI oparte na PySide6 pozostają pominięte w środowiskach bez tej biblioteki.

## Wynik regresji wydania

`python -m pytest -q`: **225 zaliczonych, 25 pominiętych, 0 błędów**.
Testy GUI pominięte, ponieważ PySide6 nie było dostępne w środowisku testowym.
