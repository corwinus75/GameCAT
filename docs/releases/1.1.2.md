# GameCAT 1.1.2 — ID segmentów i wyróżnienie bieżącego wpisu TM

**Podstawa:** GameCAT 1.1.1. **Schemat SQLite:** bez zmian, bez migracji.

## Zmiany w panelu sugestii TM

1. Przy dopasowaniu wyświetlane są **ID segmentu** i **pozycja** z aktywnego projektu, o ile istnieje segment o identycznej parze `Source`/`Target`. Lista może obejmować wiele segmentów używających tego samego tłumaczenia. Dla więcej niż trzech ID pełna lista jest w podpowiedzi (tooltip).
2. Wpis pasujący do **obu pól** aktualnie wybranego segmentu otrzymuje etykietę `BIEŻĄCY` i pogrubioną czcionkę. Pozostaje `100%`, ponieważ similarity nie może przekroczyć 100%. Jeśli w TM występuje więcej niż pięć sugestii po 100%, bieżąca para Source/Target (jeśli jest w TM) pojawia się na początku listy.
3. Gdy TM jest zewnętrzna lub importowana, wpis może nie mieć odpowiadającego segmentu w aktywnym projekcie. Wtedy panel pokazuje **brak ID segmentu w tym projekcie** i osobno **TM ID**, czyli identyfikator wiersza tabeli `translation_memory`. Nie są one tym samym.
4. Po edycji Target oznaczenie bieżącej pary jest odświeżane z 200 ms opóźnieniem, bez sztucznego dopasowania do niezatwierdzonego tekstu. Nieaktualne wyniki obliczeń są ignorowane.
5. Podwójne kliknięcie nadal wstawia Target wybranej sugestii.

## Technicznie

- `TMSegmentReference(id, position)` i opcjonalne metadane `TMMatch.segment_references`/`is_current_segment` są używane tylko w sugestiach kontekstowych z aktywnym segmentem; pozostałe wywołania `find_tm_matches` zachowują dotychczasowy rezultat i koszt.
- Repozytorium `SegmentRepository.references_for_pairs` pobiera powiązania jednym zapytaniem parametryzowanym, ograniczonym do aktywnego projektu i dokładnych par tekstowych.
- Metoda `ProjectService.find_tm_matches_async` otrzymuje migawkę ID/Target/pozycji bieżącego segmentu. Nie przekazujemy mutowalnych obiektów Qt do wątków.
- `gamecat/tm/presentation.py` zawiera niezależne od Qt formatowanie listy i tooltipów.

## Scenariusz testowy Windows

1. W projekcie z tłumaczeniami dodaj do TM zatwierdzony segment i wybierz go. W panelu powinien pojawić się pogrubiony wiersz `BIEŻĄCY · 100% · ID seg.: <id> (poz. <numer>)`.
2. Dodaj drugi segment z identyczną parą Source/Target — sugestia ma pokazywać oba ID.
3. Dodaj TM z identycznym Source, ale innym Target — to nadal `100%` similarity, lecz **bez** etykiety `BIEŻĄCY`.
4. Wybierz zewnętrzną TM zawierającą parę bez odpowiednika w projekcie — powinno być widoczne `brak ID segmentu` oraz `TM ID`.
5. Zmień Target i sprawdź, że wyróżnienie znika lub przechodzi na właściwą parę po krótkim opóźnieniu; kilka szybkich edycji nie powinno powodować błędnych podpowiedzi.
6. Sprawdź zmianę progu podobieństwa, kliknięcie dwukrotne sugestii, zamknięcie i ponowne otwarcie projektu.

**Uwagi:** indeks TM nie zawiera źródłowego ID segmentu gry dla danych spoza aktywnego projektu. Bez metadanych pochodzenia nie można bezpiecznie odtworzyć tego ID. Pozycja odpowiada kolejności w edytorze, niekoniecznie numerowi fizycznej linii pliku źródłowego.
