# GameCAT 0.10 — OpenAI API

## Zmiany

GameCAT 0.10 integruje **wyłącznie oficjalne OpenAI API** (`openai` SDK, `Responses API`).
Lokalne modele, Ollama i LM Studio nie należą do tego etapu.

- Panel **OpenAI** po prawej stronie programu oraz menu **OpenAI** (`Ctrl+Shift+T` — bieżący segment).
- Konfiguracja: model (edytowalny), indywidualny prompt projektu, limit odpowiedzi i ceny za 1 mln tokenów (osobno wejście/wyjście).
- Test połączenia z API dla aktualnie ustawionego modelu.
- Propozycja tłumaczenia bieżącego segmentu z podglądem, edycją i ręcznym zastosowaniem.
- Tłumaczenie wsadowe zaznaczonych segmentów lub pierwszych N pustych Target z dodatkowym potwierdzeniem.
- Glosariusz projektowy — wszystkie równorzędne warianty — oraz do 5 dopasowań TM jako kontekst żądania.
- QA wykonywane na odpowiedzi; wyniki bez ostrzeżeń w trybie wsadowym automatycznie zapisują Target, wyniki z problemami pozostają do ręcznej kontroli.
- Segmenty z tłumaczeniem AI oznaczane jako `[AI]`. Ręczna zmiana tekstu Target usuwa znacznik, historia statusów działa niezależnie.
- Bezpieczne zasady: brak nadpisania istniejącego Target bez zgody, domyślna ochrona REVIEWED/APPROVED, sprawdzenie aktualności Source/Target i projektu.
- Wsady można anulować (odbywające się zapytanie może dokończyć się przed zatrzymaniem).

## Konfiguracja

1. Python 3.12+. Zainstaluj zależności: `python -m pip install -r requirements.txt`.
2. Uruchom aplikację: `python main.py` i otwórz istniejący lub nowy projekt.
3. Ustaw klucz OpenAI API: najlepiej zmienna środowiskowa `OPENAI_API_KEY` albo wpisz go tymczasowo w panelu. Jeśli zaznaczysz opcję i klikniesz „Zapisz ustawienia”, GameCAT spróbuje zapisać go w systemowym magazynie poświadczeń (`keyring`). W razie braku obsługi klucz *nie jest* zapisany do lokalnego pliku i pojawi się komunikat.
4. Wybierz dostępny dla swojego konta model (np. `gpt-5-mini`) i kliknij „Test połączenia”.
5. Zapisz instrukcje tłumaczenia dla danego projektu. Nie wpisuj kluczy API do instrukcji!
6. Wybierz segment, kliknij „Tłumacz bieżący”; sprawdź QA i ewentualnie popraw odpowiedź w podglądzie przed zatwierdzeniem.
7. Przy wsadzie **koniecznie podaj aktualne ceny modelu** (USD za milion tokenów wejścia/wyjścia), maksymalną liczbę segmentów oraz budżet. Wsad wymaga potwierdzenia i domyślnie tłumaczy wyłącznie puste Target.

## Cennik i prywatność

- Ceny modeli się zmieniają. Aplikacja **nie pobiera automatycznie** cennika — 0 oznacza nieznany koszt. Szacunki dotyczą wyłącznie opłat modelu za tokeny i nie uwzględniają różnic taryf, dopłat, podatków, ewentualnego cache ani innych usług.
- Budżet w panelu jest **miękkim lokalnym ograniczeniem**, nie limitem rozliczeń OpenAI. Koszt ostateczny ustala usługa OpenAI; sprawdź rzeczywiste zużycie i limity na platformie OpenAI. Żądania w toku mogą się zakończyć i zostać naliczone mimo kliknięcia Anuluj.
- Źródłowy tekst segmentu, odpowiadające mu terminy glosariusza, maksymalnie pięć par TM i instrukcje projektu są przesyłane do zewnętrznego API. Żądania są stateless (`store=False`); nie jest to gwarancja braku wszelkich logów usługodawcy.
- Klucz API nigdy nie trafia do pliku SQLite, w tym do ustawień projektu. Nie umieszczaj go w repozytorium Git i nie przesyłaj go razem z projektem.

## Testowanie

`python -m pytest -q`, `python -m compileall -q gamecat`

Testy API używają lokalnego atrapowego klienta (bez sieci, płatności ani kluczy). Testy Qt wymagają zainstalowanego PySide6 i środowiska graficznego.
