# GameCAT 1.0.0 — wydanie zaliczeniowe

**Baza:** GameCAT 0.11.0. Nie usunięto istniejących formatów, TM, glosariusza ani modułu OpenAI API.

## Zmiany

- Wzmocniono regułę workflow przy ponownym imporcie Target: zmieniony tekst powoduje cofnięcie zatwierdzonego statusu do `TRANSLATED` lub `NEW`, a identyczny tekst zachowuje status.
- Dodano testy akceptacyjne pełnej ścieżki projektowej: JSON (profil) → import → glosariusz → QA → autosave → TM → eksport do szablonu → ponowne otwarcie.
- Powtórzono mały benchmark GIL i zachowano większy, historyczny wynik Windows w osobnym pliku. Oba pomiary mają jawne dane środowiska i nie są mieszane.
- Uaktualniono README, numer wersji oraz archiwum repozytorium.

## Weryfikacja

- `python -m pytest -q`: 160 passed, 12 skipped, 0 failed — Python 3.13.5 / Linux.
- `python -m compileall -q gamecat benchmarks tests main.py`: OK.
- Benchmark GIL: 3 tryby, 3 rundy, identyczne wyniki analizy (160×240).

## Ograniczenia

- Nie użyto rzeczywistego klucza OpenAI i nie wykonano płatnych żądań API.
- Niektóre formaty archiwów gier wymagają własnych adapterów; reserializacja JSON/XML nie zapewnia identyczności bajtowej.
